# AUDAX v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make AUDAX record on hold/toggle instead of silence detection, add user-set shortcuts, a Settings window (language, clean-up level, provider, misspellings), and four clean-up providers.

**Architecture:** A Swift menu-bar app (`AUDAX.swift`, `AUDAXWindow.swift`, new `Shortcut.swift`, new `Settings.swift`) records audio and spawns `/usr/bin/python3 dictate.py <wav>`, handing it a JSON config on stdin and reading a JSON result on stdout. `dictate.py` transcribes with whisper-cli and calls one of four clean-up providers through the new `providers.py` (urllib only).

**Tech Stack:** Swift 5 (AppKit + SwiftUI, Carbon hot keys, Security.framework Keychain), Python 3.9 stdlib, whisper.cpp, Ollama; `build.sh` (swiftc + codesign + DMG).

**Spec:** `docs/superpowers/specs/2026-10-23-audax-v2-design.md`

## Global Constraints

- Python: 3.9 syntax only; standard library only; run tests with `/usr/bin/python3`.
- Swift: compiles with `swiftc -O -swift-version 5` on macOS 13+; no Xcode project.
- Secrets (API keys, gh token) never appear in argv, environment, logs or files AUDAX writes.
- Every log line stays a one-object JSON line; `loadRecent` must keep tolerating foreign keys.
- No file deletion; the user's existing `~/.cache/mac-dictation/dictation.log` is appended, never rewritten.
- Commit after each task to the local repo created in Task 1 (no remote, no AI attribution lines).
- Build with `./build.sh`; install only in Task 7 with `./build.sh --install`.

## Review Focus

1. Talk key released within 0.3 s → "Didn't catch that", nothing transcribed or pasted (Task 1 live check 7).
2. Remote provider offline / 401 / timeout → raw text pasted, pill flashes "Pasted without clean-up", error logged without the key (Task 5 tests `test_complete_http_error_raises`, `test_cleanup_skipped_on_provider_error`; Task 3 Swift handling).
3. German umlauts survive `apply_subs` and `has_words` (Task 3 test `test_umlauts`).
4. Shortcut recorder rejects a combo without a modifier and a hands-free key equal to the talk key; a registration failure names the real combo (Task 2 live checks 3–4).
5. Malformed user `word_subs.json` → ignored with one log line, bundled defaults still apply (Task 4 test `test_user_subs_malformed`).
