# AUDAX v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fn as the hold-to-talk key (Fn+Space hands-free) with an event-tap engine, a live Copilot model picker with the responses API (default `gpt-6.1-sol`), an audible start sound, and a resident whisper server for faster speech-to-text — released as 0.3.0.

**Architecture:** Swift app (AUDAX.swift, AUDAXWindow.swift, Shortcut.swift, Settings.swift, new KeyTap.swift, new WhisperServer.swift) + Python 3.9 `dictate.py`/`providers.py`. Carbon hot keys stay for ordinary shortcuts; a `CGEvent` tap handles shortcuts involving Fn. `dictate.py` POSTs audio to `whisper-server` on 127.0.0.1:18777 and falls back to `whisper-cli`.

**Tech Stack:** Swift 5 (AppKit, SwiftUI, Carbon, CoreGraphics event taps, Security), Python 3.9 stdlib (`urllib`, hand-built multipart), whisper.cpp (`whisper-server`, `whisper-cli`), Ollama, GitHub Copilot API.

**Spec:** `docs/superpowers/specs/2026-10-24-audax-v3-addendum.md` (binding), on top of `docs/superpowers/specs/2026-10-23-audax-v2-design.md`.

## Global Constraints

- Python 3.9 syntax, standard library only; tests are plain-assert scripts (`/usr/bin/python3 test_dictate.py`, `test_providers.py`) printing only `ok`.
- Swift: `swiftc -O -swift-version 5`, `MIN_MACOS="14.0"`, zero warnings; new code: functions < 100 lines, nesting < 4, lines ≤ 100 chars.
- Secrets (gh token, API keys) never in argv, env, logs, UserDefaults or files AUDAX writes. Model-list and host caches hold ids/names/routes/hosts only.
- The app never changes macOS system settings; it may open a System Settings pane.
- No file deletion. Commit messages plain (no AI attribution). Install only in Task 4.
- Smoke runs: `AUDAX_NO_PASTE=1 CFFIXED_USER_HOME=<scratch home with .cache/mac-dictation/models symlinked> HOME=<same>`; `pkill -x AUDAX`; run the DMG binary; `kill -0` for 5 s; `pkill -USR1 AUDAX`; `sleep 0.15`; `pkill -USR1 AUDAX`; `sleep 3`; alive; one `peak_db` line in the scratch log; no `stt_s`; real log unchanged; quit; detach; `open /Applications/AUDAX.app` immediately.
- Carbon ids: 1 = talk, 2 = hands-free. `App.hotKey(id:pressed:)` is the single entry point for both engines.

## Review Focus

1. Talk = Fn and hands-free = Fn+Space: pressing Space while holding Fn must lock the running recording into hands-free, not stop it (Task 1 state machine; human check).
2. Fn alone also fires macOS's Globe-key action unless "Do Nothing"; the app must warn visibly when `AppleFnUsageType != 0` and the talk key uses Fn (Task 1; human check).
3. Accessibility not granted → the tap cannot be created: the check row must say so and the Carbon path must still work (Task 1; code review + human check).
4. A Copilot model whose route is `/responses` must get the responses body and reader; a model missing from the list must still be callable on `/chat/completions` (Task 2 tests `test_copilot_route_*`).
5. whisper-server down or slow → `whisper-cli` fallback with no change in output format (Task 3 test `test_transcribe_falls_back`).

### Task 1: Fn shortcuts — event tap engine, recorder, defaults, Globe hint

**Files:**
- Create: `KeyTap.swift`
- Modify: `Shortcut.swift`, `AUDAX.swift` (`registerHotKeys`, `hotKey`, `toggle`, `refreshChecks`, `Actions`), `Settings.swift` (Recording box hint), `AUDAXWindow.swift` (check row), `build.sh` (swiftc line)

**Interfaces:**
- `Shortcut`: `static let fnMask = UInt32(1 << 17)` (Carbon `kEventKeyModifierFnMask` value; never passed to `RegisterEventHotKey`); `var usesFn: Bool { modifiers & Shortcut.fnMask != 0 }`; `var isFnOnly: Bool { keyCode == UInt32(kVK_Function) }`; `var needsTap: Bool { usesFn }`; `static let talkDefault = Shortcut(keyCode: UInt32(kVK_Function), modifiers: fnMask)`; `static let handsFreeDefault = Shortcut(keyCode: UInt32(kVK_Space), modifiers: fnMask)`; `from(_ event: NSEvent) -> Shortcut?` accepts `keyDown` with `.function` in `modifierFlags` (adds `fnMask`) and `flagsChanged` with `keyCode == kVK_Function` and `.function` set (Fn-only); rule: nil unless ⌃, ⌥ or Fn present; `display`: "Fn" for Fn-only, "Fn" prefix otherwise (e.g. "Fn Space").
- `final class KeyTap { init?(); var onKey: ((Shortcut, Bool) -> Bool)?; func update(_ shortcuts: [(id: UInt32, shortcut: Shortcut)]); func stop(); var isActive: Bool }` — session tap (`CGEvent.tapCreate(tap: .cgSessionEventTap, place: .headInsertEventTap, options: .defaultTap, eventsOfInterest: keyDown|keyUp|flagsChanged)`), returns nil when creation fails (Accessibility missing); matches Fn-only via `flagsChanged` keyCode 63 and `.maskSecondaryFn` presence (down/up), Fn+key via `keyDown`/`keyUp` with `.maskSecondaryFn` and keyCode; calls `onKey(id, pressed)` and swallows (returns nil) matched Fn+key events; passes everything else through. Re-enables itself on `tapDisabledByTimeout`.
- `App.registerHotKeys()` registers `!needsTap` shortcuts with Carbon and hands `needsTap` ones to `keyTap.update(...)`; `App.hotKey(id:pressed:)` gains two rules: `(2, true, .recording) where mode == .hold` → `mode = .toggle` (lock hands-free; `hud.show("Hands-free")`), `(1, true, .recording) where mode == .toggle` → `finishRecording()`. UI Stop / menu / SIGUSR1 call `startDictation(mode: .toggle)` when idle and `finishRecording()` when recording (no longer via id 2).
- Globe hint: `App.globeKeyConflict: Bool` = talk or hands-free `isFnOnly` && `UserDefaults(suiteName: "com.apple.HIToolbox")?.object(forKey: "AppleFnUsageType") as? Int ?? -1 != 0`; `Actions.openKeyboardSettings` opens `x-apple.systempreferences:com.apple.Keyboard-Settings.extension`.

### Task 3: Resident whisper server with CLI fallback

**Files:**
- Create: `WhisperServer.swift`
- Modify: `dictate.py` (`transcribe`), `test_dictate.py`, `AUDAX.swift` (start/stop, `applicationWillTerminate`), `build.sh` (swiftc line)

**Interfaces:**
- Swift `final class WhisperServer { init(binary: String, model: String, port: Int); func start(); func stop(); var isRunning: Bool }` — `Process` `/opt/homebrew/bin/whisper-server -m <model> --host 127.0.0.1 --port 18777 -nt`, stdout/stderr appended to `stateDir/whisper-server.log`; restarts on unexpected exit, at most once per 60 s; `stop()` terminates; started in `applicationDidFinishLaunching` when binary and model exist; stopped in `applicationWillTerminate`.
